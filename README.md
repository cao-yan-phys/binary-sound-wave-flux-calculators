# Binary Sound-Wave Flux Calculators

[![Documentation build status](https://app.readthedocs.org/projects/binary-fluid-fluxes-calculators/badge/?version=latest)](https://binary-fluid-fluxes-calculators.readthedocs.io/en/latest/) [![arXiv:2611.29183](https://img.shields.io/badge/arXiv-2611.29183-b31b1b)](https://arxiv.org/abs/2611.29183)

Calculators for the time-averaged sound-wave fluxes generated by bound Keplerian binaries in homogeneous fluid backgrounds at rest in the binary center-of-mass frame within linear perturbation theory. The supported media are a classical inviscid Newtonian barotropic fluid and a Schrödinger-Poisson quantum fluid. See the [documentation](https://binary-fluid-fluxes-calculators.readthedocs.io/en/latest/) for details.
