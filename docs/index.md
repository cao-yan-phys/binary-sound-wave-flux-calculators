# Binary Sound-Wave Flux Calculators

Calculators for the time-averaged sound-wave fluxes generated by bound Keplerian binaries in homogeneous fluid backgrounds at rest in the binary center-of-mass frame within linear perturbation theory. The supported media are a classical inviscid Newtonian barotropic fluid and a Schrödinger-Poisson quantum fluid.

The calculators evaluate the harmonic sums with automatic convergence checks. They support CUDA acceleration through `numba.cuda` when available and can also run on the CPU.
